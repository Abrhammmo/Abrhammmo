## Favorite Project — Clinical Trial Networks Ethiopia (CTNET)

**CTNET** is a full-stack web platform developed to support and coordinate clinical research activities across Ethiopia.

As a **Full Stack Software Developer**, I contributed to the design and development of the platform, working across both the frontend and backend.

* Built the frontend using **TypeScript, React, and Vite**
* Developed the backend API using **Node.js and Express.js**
* Implemented **role-based access control** and secure authentication
* Developed **volunteer registration** and **clinical trial registry** functionality
* Added **English/Amharic bilingual support**
* Implemented **on-site SEO**, including a `sitemap.xml` to improve search engine indexability and discoverability
* Worked with researchers and stakeholders to translate requirements into functional features
* Participated in **code reviews, testing, technical documentation, and deployment preparation**
